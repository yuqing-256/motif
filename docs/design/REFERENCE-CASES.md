# Motif Reference Cases

## 1. Purpose

This file indexes selected historical and contemporary works for study. It supplies evidence and context; normative rules are defined in the Charter, Visual Language, and Composition specifications.

## 2. Case-study record

For each substantive case, record:

1. Work/page, creator, institution/publication, date, and verifiable source.
2. Relevant evidence for grid, typographic hierarchy, scale, image, geometry, color, and space.
3. Zurich-oriented structural method, Basel-oriented expressive method, and their concrete relationship.
4. How content and reader task shaped composition.
5. Transferable principles, details not to copy, and historical/contextual limits.
6. Access scope, copyright/license constraints, and actual inspection date.

Use school histories as context; analyze specific works and designer practices before drawing conclusions about their methods.

## 5. Case selection rules

Each substantive visual task must inspect at least one relevant historical/method reference and one contemporary work matching its reader task. Add photography, data, archive, or script-specific references when required. Choose the smallest case set that answers the design question; avoid open-ended research. Formal approval and task mapping are governed by `RESOURCES.md`.

## 6. Rights and use

Reference inspection is separate from asset permission. Before downloading, copying, embedding, or redistributing an image, font, or text, verify the specific object, creator, license, jurisdiction, and intended use. Record missing provenance as `unknown`.
